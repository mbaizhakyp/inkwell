# README Verification — Lecture 14

Performed on a fresh `git clone` of https://github.com/mbaizhakyp/inkwell
into an empty directory, following README.md exactly, step by step, with no
undocumented prior knowledge assumed:

- [x] `git clone` + Setup steps produce a running server — **only after fix 1**
- [x] `git clone` + Setup steps produce a running client (`npm install` + build succeed)
- [x] Every environment variable the app actually requires is documented — **after fix 2**
- [x] Every command shown in the README actually runs without modification — **after fix 3**

Result: 3 gaps found and fixed.

1. **Fresh clone crashes on boot.** Following the README, `npm run dev` failed with
   `Cannot find module '.prisma/client/default'`: nothing in the documented steps
   runs `prisma generate`, and `prisma migrate dev` did not generate the client on
   this Prisma 7 setup. Invisible on the original machine, where the client had been
   generated by hand back in Lecture 8. Fixed at the root rather than with another
   README step: `server/package.json` now has `"postinstall": "prisma generate"`
   (verified to work before any `.env` exists), so `npm install` produces a
   bootable server.
2. **`server/.env.test` was not actually gitignored.** The README (and the Lecture 13
   handout) state it is gitignored "same rule as .env", but the root `.gitignore`
   matched only the exact name `.env`; `git status` showed `.env.test` as
   untracked, one `git add .` away from being committed. Fixed: `.gitignore` now
   ignores `.env*` and re-includes `.env.example`.
3. **Port 5432 conflict.** The documented `docker run ... -p 5432:5432` fails with
   "port is already allocated" on any machine already running Postgres (this one
   included). Added a note with the fallback (publish on another port and use it in
   every `DATABASE_URL`).

Also added: the Playwright end-to-end section (root `npm install`,
`npx playwright install chromium`, `npx playwright test`), which did not exist yet.
